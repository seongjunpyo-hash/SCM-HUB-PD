🎨 scm-tokens.css CSS Variables

디자인 토큰 (color · font · sizing) 을 --scm-* CSS 변수로 정리. Production 의 styled-component 안에서 var(--scm-fg-default) 같이 참조해서 사용. F12 검증된 production 매칭 값.

color · 12 tokens typography · 11 tokens sizing · 8 tokens radius · 5 tokens
📊 ag-grid-balham-overrides.css AG Grid Theme

Production 의 AG Grid 테이블을 SCM Hub 톤으로. Sky blue 액센트 → 모노톤, 헤더 배경 → 흰색 + 검은 1.5px 보더, 행 28px → 44px, 폰트 system → Pretendard. AG Grid base CSS 다음에 import 1줄로 적용.

--ag-* override · 30+ balham theme 1줄 적용
🧩 component-styles.md Reference

버튼 (default/primary/ghost/mini), 링크, 페이지 헤더, 입력/드롭다운, 상태 칩, 필터 칩, 정보 banner 의 styled-component 레시피. 그대로 복사해서 production Emotion 코드에 붙여넣기 가능.

📦 한 번에 받기

GitHub repo 에서 prod-ready/ 폴더 통째로 다운로드 (zip):

git clone --depth 1 https://github.com/seongjunpyo-hash/SCM-HUB-PD.git
cp -r SCM-HUB-PD/prod-ready ./your-production-repo/src/styles/scm-hub-design
  1. 두 CSS 파일 (scm-tokens.css + ag-grid-balham-overrides.css) 을 production repo 의 src/styles/ 로 복사
  2. entry 파일 (main.tsx) 에 import 2줄 추가 — AG Grid base CSS 다음에
  3. AG Grid 테이블 즉시 SCM Hub 톤 적용 ✅ (1분 작업)
  4. (선택) 기존 styled-component 의 hardcoded 값을 var(--scm-*) 로 점진 교체
  5. (선택) 새 컴포넌트는 component-styles.md 레시피 그대로 복사
