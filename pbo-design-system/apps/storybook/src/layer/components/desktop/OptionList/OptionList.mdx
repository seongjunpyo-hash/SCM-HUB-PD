# OptionList

Select, MultiSelect, PopoverInput 등에서 사용되는 옵션 목록 컴포넌트입니다.  
단독으로도 사용할 수 있으나, 위의 컴포넌트와 최적화되어있어 단독으로 사용시 웹접근성 요소가 동작하지 않습니다. (방향키 이동 등)

## Anatomy

- `OptionList` - 옵션 목록의 컨테이너 (viewport)
- `OptionList.Group` - 옵션 그룹 컨테이너
- `OptionList.GroupTitle` - 그룹 제목
- `OptionList.Item` - 개별 옵션 아이템
- `OptionList.Input` - 검색 입력 필드
- `OptionList.Creatable` - 새 옵션 생성 버튼
- `OptionList.Empty` - 빈 상태 표시

## Example

```tsx
function OptionListComposition() {
  return (
    <div style={{ width: 300 }}>
      <OptionList>
        <OptionList.Group>
          <OptionList.GroupTitle title="과일" />
          <OptionList.Item value="apple" label="사과" />
          <OptionList.Item value="banana" label="바나나" />
          <OptionList.Item value="cherry" label="체리" />
        </OptionList.Group>
      </OptionList>
    </div>
  );
}
```

### Selection Type

`selectionType` prop을 통해 선택 표시 방식을 지정할 수 있습니다.

- `default`: 선택 표시 없음
- `checkMark`: 체크 아이콘 표시
- `checkBox`: 체크박스 표시 (다중 선택에 적합)

```tsx
function SelectionTypeCase() {
  const [selected, setSelected] = useState('apple');

  return (
    <Column width="300px">
      {/* default: 선택 표시 없음 */}
      <OptionList>
        <OptionList.Group>
          <OptionList.GroupTitle title="default (선택 표시 없음)" />
          <OptionList.Item value="apple" label="사과" isSelected={selected === 'apple'} selectionType="default" />
          <OptionList.Item value="banana" label="바나나" isSelected={selected === 'banana'} selectionType="default" />
        </OptionList.Group>
      </OptionList>

      {/* checkMark: 체크 아이콘 */}
      <OptionList>
        <OptionList.Group>
          <OptionList.GroupTitle title="checkMark (체크 아이콘)" />
          <OptionList.Item value="apple" label="사과" isSelected={selected === 'apple'} selectionType="checkMark" />
          <OptionList.Item value="banana" label="바나나" isSelected={selected === 'banana'} selectionType="checkMark" />
        </OptionList.Group>
      </OptionList>

      {/* checkBox: 체크박스 */}
      <OptionList>
        <OptionList.Group>
          <OptionList.GroupTitle title="checkBox (체크박스)" />
          <OptionList.Item value="apple" label="사과" isSelected={selected === 'apple'} selectionType="checkBox" />
          <OptionList.Item value="banana" label="바나나" isSelected={selected === 'banana'} selectionType="checkBox" />
        </OptionList.Group>
      </OptionList>
    </Column>
  );
}
```

### Input (검색)

`OptionList.Input`을 사용하여 옵션 검색 기능을 구현할 수 있습니다.

- `onValueChange`: 입력값 변경 시 호출
- `onClear`: 클리어 버튼 클릭 시 호출

```tsx
function InputCase() {
  const [searchValue, setSearchValue] = useState('');

  const options = [
    { value: 'apple', label: '사과' },
    { value: 'banana', label: '바나나' },
    { value: 'cherry', label: '체리' },
  ];

  const filteredOptions = options.filter((option) => option.label.includes(searchValue));

  return (
    <Column width="300px">
      <OptionList>
        <OptionList.Group>
          <OptionList.Input
            value={searchValue}
            onValueChange={setSearchValue}
            onClear={() => setSearchValue('')}
            placeholder="검색어를 입력하세요"
          />
        </OptionList.Group>
        <OptionList.Group>
          {filteredOptions.length > 0 ? (
            filteredOptions.map((option) => (
              <OptionList.Item key={option.value} value={option.value} label={option.label} />
            ))
          ) : (
            <OptionList.Empty label="검색 결과가 없습니다" />
          )}
        </OptionList.Group>
      </OptionList>
    </Column>
  );
}
```

### Creatable

`OptionList.Creatable`을 사용하여 새로운 옵션을 생성하는 UI를 제공할 수 있습니다.

```tsx
function CreatableCase() {
  const [searchValue, setSearchValue] = useState('새로운 옵션');
  const [options, setOptions] = useState([
    { value: 'apple', label: '사과' },
    { value: 'banana', label: '바나나' },
  ]);

  const handleCreate = () => {
    const newOption = { value: searchValue.toLowerCase(), label: searchValue };
    setOptions([...options, newOption]);
    setSearchValue('');
  };

  const filteredOptions = options.filter((option) => option.label.includes(searchValue));
  const isExisting = options.some((option) => option.label === searchValue);

  return (
    <Column width="300px">
      <OptionList>
        <OptionList.Group>
          <OptionList.Input
            value={searchValue}
            onValueChange={setSearchValue}
            onClear={() => setSearchValue('')}
            placeholder="검색 또는 새로 추가"
          />
        </OptionList.Group>
        <OptionList.Group>
          {filteredOptions.map((option) => (
            <OptionList.Item key={option.value} value={option.value} label={option.label} />
          ))}
          {searchValue && !isExisting && (
            <OptionList.Creatable searchValue={searchValue} label="추가" onClick={handleCreate} />
          )}
        </OptionList.Group>
      </OptionList>
    </Column>
  );
}
```

### Complex (복합 예시)

모든 기능을 조합한 복합 예시입니다.

```tsx
function ComplexCase() {
  const [searchValue, setSearchValue] = useState('');
  const [selected, setSelected] = useState<string[]>(['product1']);

  const products = [
    {
      value: 'product1',
      label: '무신사 스탠다드 티셔츠',
      subTitle: '무신사 스탠다드',
      description: '편안한 핏',
      thumbnail:
        'https://image.msscdn.net/thumbnails/images/goods_img/20240131/3836510/3836510_17152161493815_500.jpg?w=780',
    },
    // ...
  ];

  const filteredProducts = products.filter((product) => product.label.includes(searchValue));

  const handleToggle = (value: string) => {
    setSelected((prev) => (prev.includes(value) ? prev.filter((v) => v !== value) : [...prev, value]));
  };

  return (
    <Column width="400px">
      <OptionList maxHeight={400}>
        <OptionList.Group>
          <OptionList.Input
            value={searchValue}
            onValueChange={setSearchValue}
            onClear={() => setSearchValue('')}
            placeholder="상품을 검색하세요"
          />
        </OptionList.Group>
        <OptionList.Group>
          <OptionList.GroupTitle title="상품 목록" />
          {filteredProducts.length > 0 ? (
            filteredProducts.map((product) => (
              <OptionList.Item
                key={product.value}
                value={product.value}
                label={product.label}
                subTitle={product.subTitle}
                description={product.description}
                thumbnail={product.thumbnail}
                isSelected={selected.includes(product.value)}
                selectionType="checkBox"
                onClick={() => handleToggle(product.value)}
              />
            ))
          ) : (
            <OptionList.Empty label="검색 결과가 없습니다" />
          )}
        </OptionList.Group>
      </OptionList>
    </Column>
  );
}
```
