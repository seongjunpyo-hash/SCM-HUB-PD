# Checkbox

현재는 Checkbox 본체만 제공하고있으며, 그 외는 사용처에서 직접 정의하여 적용해야합니다. (ex: Label, HelperText 등...)

## Anatomy

- `Checkbox`

## Example

```tsx
function CheckboxComposition() {
  const [checked, setChecked] = useState(false);

  return <Checkbox checked={checked} onCheckedChange={setChecked} />;
}
```
