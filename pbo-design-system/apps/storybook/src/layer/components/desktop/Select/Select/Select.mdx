# Select

## Anatomy

- `Select` (기본 형태를 사용할 경우 `Select`를 사용해주세요. - 간소화된 형태로 제공)
- `Select.Root`
- `Select.Trigger`
- `Select.OptionList`
- `Select.OptionGroup`
- `Select.OptionGroupTitle`
- `Select.Option`
- `Select.OptionInput`
- `Select.OptionCreatable`
- `Select.OptionEmpty`

## Example

```tsx
function SelectComposition() {
  const [fruit, setFruit] = useState('');

  const options = [
    { value: 'apple', label: '사과' },
    { value: 'banana', label: '바나나' },
    { value: 'cherry', label: '체리' },
  ];

  return (
    <Column width="300px">
      {/* 기본 형태 */}
      <Select value={fruit} onValueChange={setFruit} options={options} placeholder="과일을 선택해주세요." />

      {/* 커스텀이 필요한 경우 */}
      <Select.Root value={fruit} onValueChange={setFruit} options={options}>
        <Select.Trigger placeholder="과일을 선택해주세요." />
        <Select.OptionList placement="bottom">
          <Select.OptionGroup>
            <Select.OptionGroupTitle title="과일1" />
            <Select.Option value="apple" label="사과" />
          </Select.OptionGroup>
          <Select.OptionGroup>
            <Select.OptionGroupTitle title="과일2" />
            <Select.Option value="banana" label="바나나" />
            <Select.Option value="cherry" label="체리" />
          </Select.OptionGroup>
        </Select.OptionList>
      </Select.Root>
    </Column>
  );
}
```

### Option Search

```tsx
function SearchCase() {
  const [fruit, setFruit] = useState('apple');
  const [input, setInput] = useState('');

  const options = [
    { value: 'apple', label: '사과' },
    { value: 'banana', label: '바나나' },
    { value: 'cherry', label: '체리' },
  ];

  return (
    <Column width="300px">
      <Select.Root value={fruit} onValueChange={setFruit} options={options}>
        <Select.Trigger placeholder="과일을 선택해주세요." />
        <Select.OptionList>
          <Select.OptionGroup>
            <Select.OptionInput value={input} onValueChange={setInput} placeholder="과일을 검색해주세요." />
          </Select.OptionGroup>
          <Select.OptionGroup>
            {options
              .filter((option) => option.label.includes(input))
              .map((option) => (
                <Select.Option key={option.value} value={option.value} label={option.label} />
              ))}
          </Select.OptionGroup>
        </Select.OptionList>
      </Select.Root>
    </Column>
  );
}
```
