# Tooltip

## Anatomy

- `Tooltip.Root`
- `Tooltip.Trigger`
- `Tooltip.Content`

## Example

```tsx
function TooltipComposition() {
  return (
    <Tooltip.Root>
      <Tooltip.Trigger>
        <Icon name="ic-alertCircle" />
      </Tooltip.Trigger>
      <Tooltip.Content>Hello~ MUSINSA</Tooltip.Content>
    </Tooltip.Root>
  );
}
```

<Story of={TooltipStories.Default} />

`action prop` 을 사용하여 Tooltip.Trigger의 액션을 설정할 수 있습니다.

```tsx
function ActionProp() {
  return (
    <Flex gap={24}>
      {/* hover */}
      <Tooltip.Root>
        <Tooltip.Trigger action="hover">
          <PrimaryButton>hover</PrimaryButton>
        </Tooltip.Trigger>
        <Tooltip.Content>Hello~ MUSINSA</Tooltip.Content>
      </Tooltip.Root>

      {/* click */}
      <Tooltip.Root>
        <Tooltip.Trigger action="click">
          <PrimaryButton>click</PrimaryButton>
        </Tooltip.Trigger>
        <Tooltip.Content>Hello~ MUSINSA</Tooltip.Content>
      </Tooltip.Root>
    </Flex>
  );
}
```
