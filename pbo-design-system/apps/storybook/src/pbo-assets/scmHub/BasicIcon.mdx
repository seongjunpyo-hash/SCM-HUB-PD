# BasicIcon

Basic 아이콘은 특정 작업, 개체 또는 개념을 나타내야합니다. 사용자 경험을 해치지 않아야 하기 때문에 장식용으로 사용하지 않습니다.

```tsx
import { Icon } from '@musinsa/pbo-assets/scmHub';

/**
 *  @prop {iconName} name - 아이콘 이름
 *  @prop {number} size - 아이콘 크기
 *  @prop {boolean} filled - 아이콘 filled 여부
 *  @prop {'100' | '150' | '200'} iconStroke - 아이콘 두께 (default: 150, filled와 같이 사용시 never 타입)
 *  @prop {string} color - 아이콘 색상
 *  @prop {ColorToken} colorToken - 아이콘 color token
 */
<Icon name="ic-orderSetting" />;
```
